# Welcome to my automation directory!

### In this directory, you will find scripts that I have created to do long or repetitive tasks that I find myself doing in my home lab and at work.
### All scripts are an example of the logic from the original scripts and you will need to plug in your own network information.
### house_keeping.sh files are scripts that create files and directories needed and update their permissions. This way you just need to copy and paste the script in using nano or vim and plug in your network info.
